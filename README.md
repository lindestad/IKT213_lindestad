# IKT213_lindestad

## Environment

This repository uses [uv](https://docs.astral.sh/uv/) to manage the virtual environment:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv sync
source .venv/bin/activate
```

Conda works as well:

```bash
conda create --name ikt213 python=3.13 opencv numpy
conda activate ikt213
```
